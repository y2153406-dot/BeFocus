
# BeFocus

BeFocus is a desktop productivity application designed to help users stay focused with customizable time tools and immersive desktop experiences.

## Tech Stack

### Frontend
- HTML
- CSS
- Vanilla JavaScript

### Desktop Application
- Electron

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

## Planned Features

- Digital Clock
- Stopwatch
- Countdown Timer
- Dynamic Wallpapers
- Floating Stopwatch Widget
- Customizable Themes
- Focus Mode
